# Deskripsi Peran
Sebagai Back-End Developer dalam tim ini, saya bertanggung jawab mengelola sisi server aplikasi. Fokus utama saya adalah membangun logika bisnis, mengatur aliran data dari dan ke database, serta menyediakan API yang aman dan andal untuk digunakan oleh sisi Front-End.

# Kontribusi Utama
Berikut adalah detail kontribusi saya dalam proyek ini:
- Perancangan Database: Membuat struktur dan relasi tabel yang efisien agar penyimpanan data rapi dan tidak redundan.
- Pembuatan RESTful API: Membangun dan mengelola endpoint untuk kebutuhan CRUD menggunakan framework Laravel.
- Autentikasi & Keamanan: Mengatur sistem keamanan, seperti fitur login dan otorisasi token, untuk melindungi akses API.
- Integrasi & Pengujian: Memastikan respons server berjalan normal, minim bug, dan siap dihubungkan dengan aplikasi Front-End.
